# Архитектура и границы переноса

`src/main.rs` содержит запуск GPUI и окно; рабочее состояние и панели живут в `src/app/*`, а данные — в соседних модулях (`draft`, `attachments`, `file_io`, `history`, `links`, `media`, `members`). Интерфейс включает ручную загрузку истории, виртуализированный список, отметки прочтения видимых сообщений и обработку событий реального времени. Для каналов подключены выбор, черновики, потоковая загрузка и атомарное сохранение вложений; личные диалоги используют тот же транспорт и черновик с ключом `server = 0`, но отдельная история ЛС ещё не встроена. Миниатюры, превью ссылок и просмотрщик изображений работают через ограниченные кеши. `crates/voxhold-api` реализует асинхронный HTTP-клиент, модели и WebSocket; `crates/voxhold-media` содержит медиаслой на Rust. Медиакрейт включён по умолчанию и использует `libwebrtc`, включающий статически слинкованную библиотеку WebRTC на C++.

Поток UI запускает сетевые операции в фоне и применяет результаты к состоянию GPUI. API-клиент ограничивает размер ответов, запрещает HTTP для нелокальных origin и не следует HTTP-перенаправлениям с токеном. Медиасигнализация использует авторизованный WebSocket. Эти меры не заменяют проверку безопасности и интеграционные испытания.

Функциональность прежнего клиента перенесена частично. Панели и последние изменения ещё не проверены сборкой и ручным запуском; наличие API-метода не означает готовый пользовательский сценарий. Оставшиеся задачи, включая вложения, администрирование, уведомления, медиа и визуальное соответствие, перечислены в [статусе](status.md).
