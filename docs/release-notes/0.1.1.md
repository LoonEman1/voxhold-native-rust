# VoxHold 0.1.1 для Windows x64

- `VoxHold-Setup.exe` устанавливает клиент, ресурсы и компонент обновления. Для переносимой установки распакуйте `VoxHold-portable.zip` в отдельный каталог.
- Клиент проверяет подпись манифеста и SHA-256 пакета. Когда для установленной версии доступна подходящая дельта, клиент загружает её. В остальных случаях он скачивает полный ZIP.
- При установке обновления клиент сохраняет пользовательские файлы и перезапускается. Если новая версия завершается до подтверждения запуска, helper восстанавливает предыдущую установку.
