# VoxHold 0.2.0 для Windows x64

- В чате снова работают быстрые реакции, ответ и пересылка из панели, которая появляется при наведении на сообщение.
- У ссылок крупнее обложки. Карточки загружаются и для сообщений у нижней границы чата. Для ссылок Steam добавлен запасной источник названия.
- В списке каналов крупнее и контрастнее текст, в панели аккаунта виден аватар. Настройки сервера доступны через шестерёнку, действия каналов и участников — по правой кнопке мыши.
- В голосовом списке у ведущего отображается красный `LIVE`, а карточка трансляции показывает её длительность и число зрителей. Индикатор речи реагирует и на собственный микрофон.
- Исправлена синхронизация захвата системного звука с отправкой в трансляцию. Короткие сбои захвата сглаживаются, чтобы уменьшить щелчки. При показе монитора режим «Системный звук без Voxhold» исключает из захвата голос комнаты и плеер клиента.
- Исправлено обрезание статуса проверки обновлений.

Для установки скачайте `VoxHold-Setup.exe`. Для переносимой версии распакуйте `VoxHold-portable.zip` в отдельную папку. Уже установленный клиент может обновиться через beta-канал по подписанному манифесту.
