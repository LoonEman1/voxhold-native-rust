# VoxHold 0.2.1 для Windows x64

## Демонстрация экрана

- Клиент запоминает настройки качества, битрейта и системного звука между запусками. Для подходящего источника доступны 1440p, 2160p и режим «Как у источника». Можно выбрать 30, 60, 90, 120, 144 или 180 FPS. Фактическая частота зависит от захвата, кодека и нагрузки. ([#46](https://github.com/LoonEman1/voxhold-native-rust/pull/46))
- Окна и мониторы прокручиваются внутри отдельного списка, поэтому кнопки остаются видны. Превью показывают кадр целиком, а длинное имя источника можно прочитать при наведении. Исправлена клавиатурная навигация после длинного списка. ([#44](https://github.com/LoonEman1/voxhold-native-rust/pull/44), [#50](https://github.com/LoonEman1/voxhold-native-rust/pull/50))
- Миниатюры в первую очередь загружаются для видимых источников. Локальное превью готовится по запросу, графические ресурсы освобождаются после использования, а голосовая панель обновляется по событиям. ([#46](https://github.com/LoonEman1/voxhold-native-rust/pull/46))
- Захват использует libyuv для преобразования кадров, а плеер готовит изображение по запросу. Исправлена потеря сигнала о получении кадра, если плеер успел прочитать изображение раньше уведомления. ([#47](https://github.com/LoonEman1/voxhold-native-rust/pull/47), [#50](https://github.com/LoonEman1/voxhold-native-rust/pull/50))

## Чат и вложения

- Чат переиспользует подготовленные строки и один загруженный эскиз вложения для разных размеров. Просмотрщик фото масштабирует общий оригинал без отдельной полноразмерной копии для каждого пересчёта. ([#45](https://github.com/LoonEman1/voxhold-native-rust/pull/45))
- Строка чата обновляется, если изменилось сообщение с той же ревизией. Запоздалые задачи миниатюр больше не перехватывают результат нового запроса. ([#50](https://github.com/LoonEman1/voxhold-native-rust/pull/50))

## Windows

- Фирменная иконка встроена в сам Voxhold.exe и отображается в Проводнике. ([#48](https://github.com/LoonEman1/voxhold-native-rust/pull/48))

В репозитории обновлён план дальнейших работ над кодеками, захватом и просмотром трансляций. ([#43](https://github.com/LoonEman1/voxhold-native-rust/pull/43))

Для установки скачайте **VoxHold-Setup.exe**. Для переносимой версии распакуйте **VoxHold-portable.zip** в отдельную папку. Уже установленный клиент может обновиться через beta-канал по подписанному манифесту.
