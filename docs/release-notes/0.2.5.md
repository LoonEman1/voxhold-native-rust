# VoxHold 0.2.5 beta для Windows x64

Изменения с версии 0.2.1.

## Обновления

- Клиент проверяет beta-канал в фоне и может заранее скачать обновление. В настройках можно независимо отключить автоматическую загрузку и установку при следующем запуске. ([#54](https://github.com/LoonEman1/voxhold-native-rust/pull/54), [#55](https://github.com/LoonEman1/voxhold-native-rust/pull/55))
- Перед установкой клиент проверяет подпись и содержимое пакета. Готовое обновление можно установить вручную, а при активном звонке или трансляции клиент сначала попросит подтверждение. Если новая версия не подтвердила запуск, установщик возвращает предыдущую версию. ([#55](https://github.com/LoonEman1/voxhold-native-rust/pull/55))
- Во время установки отдельное окно показывает текущий этап. Оно поддерживает масштаб Windows, светлую и тёмную темы и системную настройку анимаций. ([#56](https://github.com/LoonEman1/voxhold-native-rust/pull/56))

## Вход и окно

- Если включено «Запомнить вход», клиент при запуске пытается сразу открыть рабочую область. Восстановление можно отменить и выбрать другой инстанс. Явный выход сбрасывает сохранённые входы и возвращает к выбору инстанса. ([#57](https://github.com/LoonEman1/voxhold-native-rust/pull/57))
- Крестик убирает окно в системный трей. Звонок, трансляция и чат продолжают работать. Щелчок по значку возвращает окно, а команда «Выйти из Voxhold» в меню значка завершает приложение. ([#49](https://github.com/LoonEman1/voxhold-native-rust/pull/49))

## Демонстрация экрана

- В настройках трансляции появились H.264, VP8, VP9, AV1 и режим «Автоматически». Клиент запоминает выбор, объясняет недоступность кодека и показывает, когда началась передача кадров выбранным кодеком. Для смены кодека активная трансляция перезапускается. ([#58](https://github.com/LoonEman1/voxhold-native-rust/pull/58))
- При просмотре клиент проверяет, может ли декодировать предложенный кодек и профиль. Если формат недоступен, клиент сообщает причину. ([#58](https://github.com/LoonEman1/voxhold-native-rust/pull/58))

Для установки скачайте **VoxHold-Setup.exe**. Для переносимой версии распакуйте **VoxHold-portable.zip** в отдельную папку. Установленный клиент получает обновления через beta-канал по подписанному манифесту. Служебные файлы автообновления вынесены отдельно от файлов для ручной загрузки. ([#53](https://github.com/LoonEman1/voxhold-native-rust/pull/53))
