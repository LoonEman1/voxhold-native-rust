# Состояние переноса

Исходная база — локальное дерево `wgpu-desktop-parity` с незакоммиченными изменениями голоса и видео. Наблюдавшиеся ревизии: backend `9b29fdd6d5dc818b7408e4892b8e68b27d123831`, frontend `ed7cb00ae12398753a8ef48a5a33b864e20cb04c`. Полная совместимость с ними не проверена.

В исходном коде основного интерфейса подключены вход, выбор сервера и канала, участники, текстовая история с ручной загрузкой страниц и виртуализированным списком, обновления в реальном времени, поиск и закрепления, действия сообщения и обсуждения, вложения каналов, отметки прочтения видимых сообщений, недавние диалоги, личные настройки, настройки канала и сервера. Административные панели включают название, CORS, баны, экспорт диагностики и применимые к типу канала параметры. Имеются панели голоса и просмотра видео с ограниченными переключением и восстановлением; медиакрейт включён по умолчанию. Для вложений каналов подключены выбор файлов, черновики, загрузка и сохранение; передача буферизуется в памяти. Наличие элемента или метода не подтверждает работу соответствующего сценария на сервере.

До паритета остаются, среди прочего: проверка и завершение личных сообщений, настроек и администрирования, включая роли и квоты; вложения личных диалогов, аватары и предпросмотр; системные уведомления и тема; устойчивое переподключение; завершение голосовых и видеосценариев, выбора устройств и трансляций. Визуальное соответствие веб-клиенту, ассеты, адаптивность и доступность также требуют работы. Необходимо проверить права, E2EE, новостные каналы и личные диалоги с сервером. Измерений производительности нет.

Проверено на Windows x64: `cargo build --release --locked -p voxhold-native-rust` с включённым медиа завершился успешно; `cargo check --locked -p voxhold-native-rust` успешен; тесты API 4/4 и media 6/6 успешны. Проверка запуска обнаружила отзывчивое окно приложения; пользовательские сценарии и работа с реальным backend не проверены. Выполняемый файл использует системные Windows DLL, отдельная DLL медиадвижка не нужна. Ресурсы и иконки компонентов требуют визуальной проверки. API запрещает удалённый HTTP и HTTP-перенаправления с токеном. Медиазависимость по умолчанию включает статически слинкованный C++ `libwebrtc`.
